# Spring Security Basic Auth Example

A **minimal full-stack app** demonstrating **HTTP Basic Authentication** with Spring Boot, Spring Security, and a simple JavaScript frontend.

---

## 🎯 Summary
- Learn to Basic Auth with Spring Security  
- Understand **frontend-backend communication** over secured endpoints  
- Lightweight template for prototype

---

## ⚙️ Tech Stack
- 🟢 **Backend:** Spring Boot, Spring Web  
- 🔒 **Security:** Spring Security (Basic Auth)  
- 🗄️ **Data :** PostgreSQL, Spring Data JPA  
- 🌐 **Frontend:** JavaScript
- 🐳 **Infra:** Docker & Docker Compose  

---

## 🚀 Getting Started

### 1. Clone
```bash
git clone https://github.com/cherkashin-de/spring-security-basic-auth-example.git
cd spring-security-basic-auth-example
```

### 2. Docker start 🐳
```bash
docker-compose up --build
```
